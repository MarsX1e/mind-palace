# 思维殿堂 · 快速上手指南

这个知识库由两部分配合工作：

- **Obsidian** —— 管理你的笔记、素材卡片（日常记录、写作都用它）
- **AnythingLLM** —— 导入书籍扫描和笔记，向 AI 提问、检索素材（问答用它）

---

## 一、目录说明

| 目录 | 用途 |
|---|---|
| `00-影像资料` | 手机照片和视频（含GPS地理信息）。`索引` 里是由脚本生成的影像目录 |
| `01-书籍扫描` | 存放书籍 PDF。`待OCR` 放纯图片扫描件，`已OCR` 放已识别出文字的 PDF |
| `02-笔记` | Obsidian 笔记（读书笔记、知识记录都写在这里） |
| `03-素材卡片` | 写作素材卡片：一条灵感、一个案例、一段金句一张卡，方便检索引用 |
| `04-写作项目` | 你的文章/书稿项目 |
| `05-AI问答导出` | 从 AnythingLLM 导出的问答记录，值得留存的放这里 |
| `99-软件安装包` | 软件安装包（装完可删） |

---

## 二、安装软件（约 10 分钟）

安装包比较大（Obsidian 约 100MB，AnythingLLM 约 400MB），请用浏览器打开下面的链接下载，下载后可放进 `99-软件安装包` 备用：

1. **Obsidian**：https://obsidian.md/download → 选 Windows 版。
2. **AnythingLLM**：
   - 官网下载页：https://anythingllm.com/download → 选 Windows (x86_64)
   - 或直接下载：https://github.com/Mintplex-Labs/anything-llm/releases/download/v1.17.0/AnythingLLMDesktop.exe

首次配置 AnythingLLM：

- LLM 提供商选 **DeepSeek**（便宜、中文好）
- 去 [platform.deepseek.com](https://platform.deepseek.com) 注册，充 10 元左右，创建 API Key，填进去
- Embedding（向量模型）选它默认的即可

装 Obsidian 后：「打开库 → 选择本文件夹（C:\知识库）」，你的整个知识库就变成一个笔记本。

> 两个软件都装在本地，你的文件始终存在自己电脑上；只有提问时相关内容片段会发给 DeepSeek API。

## 三、日常使用流程

### 1. 存入一本书 / 一条知识
- 文字版 PDF → 直接放进 `01-书籍扫描\已OCR`
- 图片扫描件 → 用 **Umi-OCR**（免费开源，见附录）识别成文字，存成 PDF/文本后放进 `已OCR`
- 自己了解到的东西 → 在 Obsidian 里写进 `02-笔记` 或 `03-素材卡片`

### 2. 让 AI 帮你找素材
1. 打开 AnythingLLM，把 `01-书籍扫描\已OCR` 里的文件和 `02-笔记`、`03-素材卡片` 拖进工作区（它会自动切块建索引）
2. 像聊天一样提问，例如：
   - 「关于'习惯养成'，我书里都有哪些论述？注明出处」
   - 「帮我找三个关于'拖延症'的论据，素材卡片和书里的都要」
   - 「把这些内容整理成一篇文章的提纲」
3. 有价值的回答 → 导出存到 `05-AI问答导出`

### 3. 写作时
在 Obsidian 的 `04-写作项目` 里写稿，引用 `03-素材卡片` 的素材；随时开 AnythingLLM 查漏补缺。

## 三点五、照片和视频（按拍摄地点检索）

知识库可以接收华为手机拍摄的照片和视频，并保留 GPS 地理信息。之后对 AI 说「我需要一些新疆的风貌」，它就能按拍摄地点找出新疆的照片。

### 1. 拍摄时：打开相机的位置记录
华为手机：相机 → 设置 → 开启「**记录地理位置信息**」。只对新拍的照片/视频生效，旧照片如果没有 GPS 就无法按地点检索。

### 2. 导入电脑：必须保住 GPS 信息
- **推荐**：数据线连接电脑 → 手机选「传输文件」→ 复制 `DCIM/Camera` 里的原图到 `00-影像资料\照片原图`、`Movies` 里的视频到 `00-影像资料\视频原图`
- **不要用微信/QQ传图**——它们会压缩并抹掉 GPS 信息，这是最常见的失败原因
- 蓝牙、华为分享（Huawei Share）传原图也可以

### 3. 生成可检索的影像目录
1. 申请免费的高德 API 密钥：打开 https://lbs.amap.com 注册 → 「应用管理」→ 创建应用（类型选 Web 服务）→ 得到一串 key
2. 用记事本打开 `tools\影像建索引.py`，把 key 填到开头的 `高德API密钥 = ""` 里
3. 双击运行（或在知识库文件夹按住 Shift 右键 → 「在此处打开 PowerShell」→ 输入 `python tools\影像建索引.py`）
4. 脚本会读取每个照片/视频的 GPS 坐标 → 自动查出「省/市/区县/附近地标」→ 生成 `00-影像资料\索引\影像总目录.md`
5. 把这个 md 文件拖进 AnythingLLM 工作区，以后就能按地点问 AI 了

> 视频和 HEIC 格式照片需要 ExifTool：从 https://exiftool.org 下载 Windows 版，把 `exiftool(-k).exe` 改名为 `exiftool.exe` 放到 `tools` 文件夹。普通 jpg 照片不需要它。

### 4. 新照片怎么更新？
复制进 `照片原图` 后重新运行一次脚本即可（有缓存，很快）。然后在 AnythingLLM 里重新导入更新后的 `影像总目录.md`。

## 四、几个让效果变好的习惯

- **素材卡片格式统一**：每张卡开头写 `#标签`，如 `#习惯 #拖延 #金句`，AI 检索会更准
- **定期把新笔记同步进 AnythingLLM**：新文件拖进去即可，它会增量索引
- **提问时要求"注明出处"**：方便你回到原书核对原文
- **大书按章节拆 PDF**：索引更细，回答更精准

## 附录：Umi-OCR（图片扫描件识别）

免费、开源、纯本地运行（图片不出电脑）：
- 下载页：https://github.com/hiroi-sora/Umi-OCR/releases → 选 `Umi-OCR_PaddleOCR-v2.x.x.exe`（Windows 整合包）
- 用法：打开软件 → 批量导入图片/PDF → 输出选「Markdown 或 纯文本」→ 识别结果保存为文本文件，再放进 `01-书籍扫描\已OCR`

## 附录：隐私提示

- 本地文件、Obsidian 笔记：完全在你电脑上
- 发给云端 API 的：只有提问时相关的片段。介意的内容可以不导入 AnythingLLM，只在 Obsidian 里保存
