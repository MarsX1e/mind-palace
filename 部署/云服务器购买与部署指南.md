# 云服务器购买与部署指南

> 目标：把手机知识库从"家里电脑"搬到"云服务器"，出门也能用。
> 全程约 1-2 小时（其中大部分是文件上传的等待时间）。

---

## 第一步：买服务器

### 1. 注册阿里云

1. 浏览器打开 **https://www.aliyun.com**
2. 右上角「注册」→ 用手机号注册 → 登录
3. **完成实名认证**（必须，否则不能买）：控制台 → 右上角头像 → 实名认证 → 个人认证，按提示上传身份证

### 2. 找到轻量应用服务器

- 产品入口：**https://www.aliyun.com/product/swas**
- 或：阿里云首页 → 顶部「产品」→ 搜索「轻量应用服务器」

### 3. 选配置

| 项目 | 选择 |
|---|---|
| 地域 | 选离你最近的城市（如杭州、北京、深圳） |
| 镜像（系统） | **系统镜像 → Windows Server 2022** |
| 配置 | **2 核 4G**（推荐）或 2 核 2G（省钱，但跑 Windows 偏紧） |
| 系统盘 | **60GB 以上**（你的照片+视频约 4GB，还要留余量） |
| 带宽 | 选带 200M 峰值带宽的套餐（看视频更流畅） |
| 时长 | 1 年 |

**价格参考**（2026 年阿里云轻量活动价，[来源文章](https://developer.aliyun.com/article/1768045)、[官方定价页](https://www.alibabacloud.com/zh/product/swas/pricing)）：

- 2核2G：活动价约 38–68 元/年
- 2核4G：约 379 元/年
- ⚠️ **Windows 系统的价格通常高于 Linux**（含授权费），具体以购买页面显示为准

> 如果阿里云的 Windows 机型太贵，可以换 **腾讯云轻量应用服务器**，同样支持 Windows Server 2022，操作方式完全一样。

### 4. 购买后要做的两件事

在**控制台 → 轻量应用服务器 → 你的实例**里：

1. **拿到公网 IP**：实例详情页顶部就有（形如 `47.98.x.x`）
2. **设置 Administrator 密码**：详情页 →「重置密码」（或购买时已设置）→ 记下来
3. **放行端口**：详情页 →「防火墙」→ 添加规则 → 协议 **TCP**、端口 **8000**、来源 `0.0.0.0/0`

## 第二步：把资料传上服务器

1. 在自己电脑上：`Win + R` → 输入 `mstsc` → 回车（打开远程桌面）
2. 计算机填**服务器公网 IP** → 连接 → 用户名 `Administrator` + 你设的密码
3. 连接前先点「显示选项」→「本地资源」→「详细信息」→ 勾选 **驱动器**（这样服务器里能直接看到你电脑的 D 盘）
4. 进入服务器桌面后，打开「此电脑」，会看到类似 `D 位于 ...` 的重定向磁盘
5. 把电脑上的 `C:\知识库` **整个文件夹**复制到服务器的 **`C:\知识库`**

> 提示：文件约 4GB，通过远程桌面复制需要一段时间（取决于你家宽带上传速度）。
> 想快一点：先在服务器上以管理员身份打开 PowerShell，执行下面这条（把 X 换成重定向盘的盘符），
> 让它后台跑，你该干嘛干嘛：
> ```powershell
> robocopy "X:\知识库" "C:\知识库" /E /MT:16 /R:1 /W:1
> ```

---

## 第三步：一键部署

1. 先把 `C:\知识库\部署\服务器一键部署.ps1` 也复制到服务器（如果整个文件夹都复制了，它已经在里面）
2. 在**服务器上**：开始菜单 → 搜索 `PowerShell` → **右键 → 以管理员身份运行**
3. 打开脚本文件，**全选复制其内容**，粘贴到 PowerShell 窗口，回车

脚本会自动完成：

- 检测/安装 Python（从国内镜像下载，几分钟）
- 安装 fastapi / uvicorn / pypdf / pillow
- 写入访问密码（`server\access_token.txt`）
- 放行 Windows 防火墙 8000 端口
- 注册**开机自启**服务（任务计划程序，任务名"思维殿堂服务"）
- 自检并打印手机访问地址和密码

看到这一行就成功了：

```
部署完成！
手机访问地址：http://你的IP:8000
访问密码：xxxxxxxxxx
```

> 想自定义密码：运行前把脚本里 `$访问密码 = ""` 改成你要的密码（留空会自动生成随机密码）。

---

## 第四步：手机验证

1. 手机**关掉 WiFi，用 4G/5G**（确保是外网访问）
2. 浏览器打开 `http://你的IP:8000`
3. 输入访问密码 → 进入知识库
4. 浏览器菜单 →「添加到主屏幕」，以后就像 App 一样打开

---

## 日常维护

| 需求 | 操作 |
|---|---|
| 看服务日志 | 服务器上打开 `C:\知识库\server\server.log` |
| 重启服务 | 服务器上：任务计划程序 → 找到"思维殿堂服务" → 右键「运行」 |
| 改访问密码 | 修改 `C:\知识库\server\access_token.txt` 内容 → 重启服务 |
| 新增资料 | 直接在手机上传，或远程桌面复制进对应文件夹 |
| 磁盘满了 | 把老视频移回本地电脑，只保留索引（检索不受影响） |

---

## 安全说明

- 网页需要密码才能进入，密码保存在服务器的 `server\access_token.txt`
- 服务器上的 `deepseek_key.txt`、`阿里云 API Key` 都在服务器本地，不会外传
- 建议：**不要**把服务器密码和访问密码设为同一个；定期更换
- 进阶（可选）：注册域名 + ICP 备案后，可配置 HTTPS 和域名访问（`http://` 变 `https://`，更安全更正式）
