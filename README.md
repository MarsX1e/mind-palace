# 思维殿堂 · Mind Palace

### 用 AI 检索你的照片、视频与书籍

一个**跑在自己服务器上、用手机随时访问**的私人知识库系统。

把书籍 PDF、日常笔记、手机拍的照片和视频统统丢进去，之后用自然语言提问：
「给我一些新疆的风貌」「找一下假黄金熔炼的视频」「论文里关于轧制温度是怎么说的，第几页？」
——它会翻你的书、翻你的相册、翻你的视频描述，把**文字答案 + 照片 + 可播放的视频 + 书籍页码直达链接**一起给你。

> 名字取自福尔摩斯的"记忆宫殿"（Mind Palace）：把看过、拍过、读过的一切都放进一座随时可以走进去翻找的殿堂。

---

## ✨ 功能特性

### 📷 照片：AI 识图 + 地理信息检索
- 上传照片自动调用视觉大模型（阿里云百炼 Qwen-VL）生成中文描述
- 读取照片 EXIF 里的 GPS 坐标，通过高德地图反向解析出**省/市/区/附近地标**
- 提问时返回**缩略图墙**，点开看大图（自研感知指纹去重，重复照片自动跳过）

### 🎬 视频：边播边写描述，像刷短视频一样过片
- 自动提取**视频首帧**作为封面，横向封面条一眼看清有哪些片子
- 点哪条立即播放，下方就是描述输入框；「保存并下一个」自动跳转下一条未描述视频
- 顶部实时显示"还有 N 个视频未描述"
- 查询结果里匹配到的视频**可以直接点播**

### 📚 书籍 / 论文：回答带页码，一键跳转
- 文字版 PDF 自动按页提取（每页打上【第N页】标记）
- 回答涉及书籍内容时**注明出自哪本书第几页**
- 提供「精确出处」列表，点一下**直接打开 PDF 并跳到该页**

### 🔍 AI 问答
- 基于 DeepSeek，只根据你的资料回答，并注明出处
- 资料按类别分配预算（影像 / 书籍 / 笔记），不会被某一类挤爆上下文

### ⬆️ 手机端
- 三个标签页：**查询 / 写描述 / 上传**，浏览器打开即用，可"添加到主屏幕"当 App
- 手机直接上传照片视频，后台自动 AI 识图 + 更新索引

### 🧠 智能检索（RAG）
- 资料切段后用 `text-embedding-v3`（支持 50+ 语言）向量化，提问时只把**最相关的片段**交给 AI
- **跨语言检索**：用中文提问，也能命中英文/日文等外文原文
- 不受"上下文长度"限制，书籍从几本扩到几百本都不用改代码
- 检索结果带**文件名 + 页码**，书籍内容可一键跳转原文
- 每次提问只送 10-20 段，**token 消耗比全量塞入降低约 90%**

### 🔒 安全
- 访问密码 + **登录失败限速**（同一 IP 10 次失败锁定 10 分钟）
- 支持 **HTTPS（自签名证书）**，传输全程加密
- 照片/视频/PDF 请求也带鉴权（支持 `?token=` 形式，供 `<img>`/`<video>` 标签使用）

## 🚀 快速开始

### 0. 环境要求

| 依赖 | 说明 |
|---|---|
| Python 3.10+ | 主程序 |
| [ffmpeg](https://www.gyan.dev/ffmpeg/builds/) | 视频首帧提取（把 `ffmpeg.exe` 放进 `tools/`） |
| [ExifTool](https://exiftool.org/) | 读取视频/HEIC 的 GPS（把 `exiftool.exe` 放进 `tools/`） |

### 1. 获取代码并安装依赖

```bash
git clone https://github.com/MarsX1e/mind-palace knowledge-base
cd knowledge-base
pip install fastapi uvicorn pypdf pillow cryptography numpy
```

### 2. 填入你自己的 API Key（**必须**）

复制模板并填写：

```bash
cp config.example.json config.json
```

```json
{
  "DeepSeekKey": "sk-你的DeepSeek密钥",
  "阿里云Key": "sk-你的阿里云百炼密钥",
  "高德Key": "你的高德Web服务Key",
  "识图模型": "qwen3-vl-plus",
  "访问密码": "自定义一个访问密码，留空则不校验"
}
```

三个 Key 的申请方式见下方 [API Key 申请指南](#-api-key-申请指南)。**不填 Key 也能启动**，只是对应的 AI 功能不可用。

### 3. 启动

```bash
cd server
python -m uvicorn app:app --host 0.0.0.0 --port 8000
```

浏览器打开 `http://127.0.0.1:8000` 即可。手机访问用 `http://<电脑局域网IP>:8000`。

## 🔑 API Key 申请指南

### DeepSeek（AI 问答，必需）
1. 打开 https://platform.deepseek.com 注册
2. 充值 10 元（够用很久）
3. 「API Keys」→ 创建 → 复制 `sk-` 开头的串
4. 填到 `config.json` 的 `DeepSeekKey`

### 阿里云百炼（照片识图，可选）
1. 打开 https://bailian.console.aliyun.com 开通百炼
2. 右上角头像 → 「API-KEY」→ 创建
3. 填到 `config.json` 的 `阿里云Key`
4. 模型默认 `qwen3-vl-plus`（也可换成控制台里其他 VL 模型）
5. 费用参考：一张压缩后的照片约几厘钱

### 高德地图（照片地理位置解析，可选）
1. 打开 https://lbs.amap.com 注册（个人开发者免费）
2. 控制台 → 应用管理 → 创建应用 → **添加 Key**
3. ⚠️ **服务平台必须选「Web服务」**，不要设置安全密钥
4. 填到 `config.json` 的 `高德Key`
5. 免费额度：逆地理编码每日数千次，脚本带缓存，够个人使用

> 不填高德 Key 也能用：照片会按 GPS 坐标入库，只是没有"省/市/区"地名。

├── 02-笔记/  03-素材卡片/       # 你的文字资料

## ☁️ 部署到云服务器（可选，随时随地问）

本地跑只能在家里 WiFi 用。想让手机在外面也能用，需要一台云服务器：

1. 买一台**轻量应用服务器**（阿里云/腾讯云，Windows Server 2022 或 Ubuntu，2核2G 起）
2. 参考 [部署/云服务器购买与部署指南.md](部署/云服务器购买与部署指南.md)
3. 一键部署脚本会自动完成：装 Python → 装依赖 → 生成 HTTPS 证书 → 设置访问密码 → 放行防火墙 → 注册开机自启

⚠️ **隐私提醒**：无论本地还是云端，AI 问答时**资料片段会发送给 DeepSeek / 阿里云**。敏感资料建议不要放进检索库。

## 🎯 使用说明

打开网页后有三个标签页：

| 标签 | 用途 |
|---|---|
| **查询** | 自然语言提问，返回文字答案 + 照片墙 + 可播放视频 + 书籍页码直达 |
| **写描述** | 显示还剩多少视频没写描述；点封面即播，边看边写，自动跳下一条 |
| **上传** | 手机选照片/视频上传，后台自动识图并更新索引；另有重复影像清理 |

**推荐工作流**
1. 先把书籍 PDF 放进 `01-书籍扫描/已OCR/`
2. 手机拍的照片视频用网页「上传」传进去
3. 定期在「写描述」里把视频描述补完（AI 搜视频全靠这些描述）
4. 想找素材时直接提问

## 🛠 技术栈

- **后端**：Python + FastAPI + Uvicorn
- **前端**：单文件原生 HTML/JS（无构建步骤，手机优先）
- **AI**：DeepSeek（文本问答） + 阿里云百炼 Qwen-VL（照片识图）
- **影像处理**：Pillow（缩略图/感知指纹） + ffmpeg（视频首帧） + ExifTool（GPS 读取）
- **地理位置**：高德地图逆地理编码 API
- **部署**：Windows 任务计划 / systemd，自签名 HTTPS

## ❓ 常见问题

**Q：报 `ModuleNotFoundError: No module named 'fastapi'`**
A：`pip install fastapi uvicorn pypdf pillow cryptography numpy`

**Q：视频没有封面、不显示首帧**
A：把 `ffmpeg.exe` 放到 `tools/` 目录（Windows），或 `apt install ffmpeg`（Linux）

**Q：照片没有"拍摄地点"**
A：① 拍摄时手机要开启「记录地理位置信息」；② 在 `config.json` 填高德 Key；③ 微信/QQ 传图会抹掉 GPS，请用数据线或网盘传原图

**Q：PowerShell 脚本报中文乱码 / 语法错误**
A：脚本必须保存为**带 BOM 的 UTF-8**（Windows PowerShell 5.1 需要 BOM 才能正确读中文）。仓库内已全部处理

**Q：HTTPS 用 PowerShell 测不通，但浏览器能开**
A：PowerShell 5.1 默认只用 TLS 1.0，脚本里需加 `[System.Net.ServicePointManager]::SecurityProtocol = 'Tls12'`

**Q：AI 找不到某些资料**
A：检查是否超出上下文预算（默认 12 万字符）；影像/书籍/笔记各有独立预算，见 `server/app.py` 的 `收集资料()`

**Q：费用大概多少？**
A：服务器约 100-400 元/年；DeepSeek 每次提问几分钱；照片识图每张几厘钱
